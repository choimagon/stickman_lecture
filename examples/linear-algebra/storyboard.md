# 고유벡터와 고유값 스토리보드

대상은 학부생이며 전체 길이는 90초다. 각 장면은 15초다.

## 0–15초 · 왜 고유방향을 찾을까

학습 목표: 변환에서 방향이 유지되는 벡터의 의미를 안다.

내레이션: 변환해도 방향이 유지되는 벡터를 찾아봅시다.

화면: 복잡한 변환도 특별한 방향에서는 단순합니다

## 15–30초 · 방향은 그대로

학습 목표: 고유벡터의 방향과 길이 변화를 이해한다.

내레이션: 고유벡터는 변환 후에도 같은 직선 위에 있습니다.

화면: vector → vector → 파란색: v     주황색: Av

## 30–45초 · 계산 예시와 반례

학습 목표: 행렬을 적용해 고유벡터와 반례를 구분한다.

내레이션: 가로 벡터는 고유벡터지만 대각 벡터는 아닙니다.

화면: A=\begin{bmatrix}2&0\\0&1\end{bmatrix},\quad v=\begin{bmatrix}1\\0\end{bmatrix},\quad Av=\begin{bmatrix}2\\0\end{bmatrix} → w=\begin{bmatrix}1\\1\end{bmatrix},\quad Aw=\begin{bmatrix}2\\1\end{bmatrix} → Aw는 w와 평행하지 않습니다

## 45–60초 · 고유값 방정식

학습 목표: 고유벡터와 고유값을 식으로 정의한다.

내레이션: 영벡터가 아닌 벡터가 스칼라 배가 되면 고유벡터입니다.

화면: A\mathbf{v}=\lambda\mathbf{v},\quad \mathbf{v}\ne\mathbf{0} → λ는 길이와 방향의 배율입니다

## 60–75초 · 고유값을 바꿔 보기

학습 목표: 고유값에 따른 고유벡터의 길이 변화를 관찰한다.

내레이션: 가로 배율을 바꾸면 고유방향은 유지되고 길이가 바뀝니다.

화면: A=\operatorname{diag}(s,1),\quad v=(1,0) → line → vector → 청록색: Av. 같은 가로 직선 위에 있습니다

상호작용: 고유값 s 슬라이더로 변화를 관찰한다.

## 75–90초 · 고유방향을 기억하기

학습 목표: 고유벡터의 정의와 반례를 요약한다.

내레이션: 고유벡터는 변환 후 원래 직선 위에 남습니다.

화면: A\mathbf{v}=\lambda\mathbf{v},\quad \mathbf{v}\ne\mathbf{0} → 방향이 달라지는 벡터는 고유벡터가 아닙니다
