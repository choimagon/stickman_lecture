# 도형과 화살표로 설명하는 물의 순환

56초 동안 물이 지표에서 하늘로 올라갔다 다시 돌아오는 대표 경로를 보여 준다. 도형은 장소나 물의 상태를, 화살표는 에너지와 물이 이동하는 방향을 나타낸다.

| 시각 | 그리는 요소 | 말풍선의 설명 |
| --- | --- | --- |
| 0–6초 | 바다와 호수의 사각형, 태양의 원 | 물이 모여 있는 곳과 에너지가 오는 곳을 구분한다. |
| 6–18초 | 태양에서 물로 향하는 화살표, 위로 향하는 화살표 | 태양 에너지가 물을 데우면 일부가 수증기가 되어 올라간다. |
| 18–25초 | 상승과 냉각을 나타내는 화살표 | 수증기를 포함한 공기가 위로 올라가 식으면 작은 물방울이 된다. |
| 25–36초 | 구름 타원 | 작은 물방울이 많이 모이면 구름을 이룬다. |
| 36–44초 | 구름, 지표 다각형과 아래로 향하는 화살표 | 커진 물방울이나 얼음 알갱이가 비나 눈으로 떨어진다. |
| 44–50초 | 하천 꺾은선, 바다로 향하는 화살표와 사각형 | 강수의 일부가 지표를 따라 흐르고 하천을 거쳐 바다로 들어간다. |
| 50–56초 | 완성된 물의 경로 | 바다로 돌아온 물 일부가 다시 증발하면서 순환한다. |
