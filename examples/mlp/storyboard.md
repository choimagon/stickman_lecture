# 다층 퍼셉트론의 순전파

학부 초심자를 대상으로 한 124초 강의다. 입력 두 개, ReLU 은닉 뉴런 두 개, 출력 하나로 구성된 신경망을 한 번 계산한다. 화살표를 긋는 동안 말풍선으로 각 연결이 전달하는 값과 가중치를 설명한다.

| 시각 | 장면 | 학습 내용 |
| --- | --- | --- |
| 0–8초 | 예측 문제 | 두 입력의 서로 다른 조합으로 한 값을 예측한다. |
| 8–16초 | 입력 노드 | x₁과 x₂는 같은 대상의 두 특성이다. 예시 값은 각각 2와 1이다. |
| 16–42초 | 연결과 가중치 | 각 화살표를 입력에서 은닉층으로, 은닉층에서 출력으로 긋는다. 각 연결의 부호와 크기를 소개한다. |
| 42–50초 | 첫 은닉 뉴런의 가중합 | z₁=1·x₁−1·x₂+0=1이다. 편향은 입력과 별도로 더한다. |
| 50–58초 | 둘째 은닉 뉴런의 가중합 | z₂=−1·x₁+2·x₂+1=1이다. 입력은 같아도 가중치와 편향은 다르다. |
| 58–66초 | 첫 활성값 | h₁=ReLU(z₁)=1이다. |
| 66–76초 | ReLU 그래프 | 축, 음수 구간의 수평선, 양수 구간의 대각선을 순서대로 긋는다. |
| 76–84초 | 둘째 활성값 | h₂=ReLU(z₂)=1이다. 두 활성값은 뉴런마다 따로 계산한다. |
| 84–92초 | 출력 뉴런 | 출력 편향은 0이다. y=2h₁+h₂=3을 계산한다. |
| 92–100초 | 입력 슬라이더 | x₁이 움직이면 h₁, h₂와 출력의 숫자 및 막대가 함께 바뀐다. |
| 100–108초 | 음수 가중합 확인 | x₁=0인 예에서 z₁=−1, h₁=0, z₂=3, h₂=3이다. 출력은 3이다. |
| 108–116초 | 출력과 학습 | 출력 활성화는 항등 함수다. 가중치와 편향은 학습이 끝난 상태로 주어진다. |
| 116–124초 | 순서 되짚기 | 입력에서 가중합과 편향, ReLU, 출력 가중합 순으로 진행한다. |

웹에서 x₁을 2에서 4로 바꾸면 첫 활성값은 3이 되고 둘째 활성값은 0이 된다. 출력은 3에서 6이 된다.
