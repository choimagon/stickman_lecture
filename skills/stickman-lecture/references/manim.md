# 비디오 렌더링

Manim Community Edition의 Cairo 렌더러가 수식, 그래프, 벡터, 텍스트를 그린다. LaTeX 문자열은 MathJax로 SVG 경로로 변환한 뒤 Manim `SVGMobject`로 가져온다. 따라서 이 파이프라인은 시스템 LaTeX를 요구하지 않는다. KaTeX와 MathJax가 모두 지원하는 기본 및 AMS 수식 구문을 우선 사용한다.

이벤트가 나뉘는 프레임마다 수학 레이어를 구성한다. 그래프의 좌표와 화살촉은 웹과 같은 함수에서 계산한다. 슬라이더 값은 영상에서 기본값으로 고정된다. 선과 도형의 진행 중간 프레임도 공통 경로에서 계산해 Manim에서 그린다. 캐릭터와 말풍선은 같은 프레임 인덱스의 투명 Canvas로 그린 다음 FFmpeg로 합성한다.

영상은 보이는 말풍선의 글자 수에 맞춰 읽는 시간을 자동으로 조정한다. 도형을 그리는 속도는 유지한다. 원래 장면 시간을 사용하려면 `--fixed-timing`을 지정한다. `both` 모드의 웹은 영상과 같은 조정된 시간표를 사용하고 웹 전용 출력은 기존 시간표를 사용한다.

MP4에는 말풍선이 나타나거나 바뀔 때와 그래프·선, 화살표, 도형·점, 수식이 등장할 때 각각 어울리는 짧은 효과음이 기본으로 들어간다. `--no-bubble-sound`는 말풍선 효과음만 끄고 `--no-effects`는 모든 효과음을 끈다. `--audio /path/to/file`은 사용자가 제공한 오디오를 함께 추가한다. 웹 출력에는 이 효과음이 적용되지 않는다.

영상 출력에는 `lesson.mp4`와 함께 `player.html`이 생성된다. 플레이어에서 장면을 선택하면 영상의 해당 위치로 이동하고 재생 위치를 옮기면 현재 장면이 갱신된다. 두 파일을 같은 폴더에 보관하면 오프라인으로 열 수 있다. 기존 렌더 결과에는 저장된 장면과 MP4를 사용해 `stickman-lecture player output/<예제 이름>`으로 플레이어를 추가할 수 있다. `web/index.html`은 슬라이더 등을 조작하는 별도의 웹 출력이다.

`--preview`는 비디오 픽셀 크기만 줄인다. 한국어 Pango 글꼴 선택이 필요할 경우 `MATHSCENE_KOREAN_FONT`를 지정한다.
