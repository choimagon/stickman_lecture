# 설명 설계

설명할 대상과 최종 상태를 먼저 정한다. 다이어그램만 보고도 구성 요소와 연결 방향을 따라갈 수 있게 구성한다.

1. 주제를 이해하면 답할 수 있는 질문이나 수행할 수 있는 과정을 제시한다.
2. 공간이나 흐름의 기준을 먼저 그린다. 배경, 축, 입력부, 경계처럼 이후 요소의 위치를 결정하는 부분이 여기에 해당한다.
3. 도형이나 노드를 순서대로 추가한다. 무엇인지, 무엇을 받거나 내보내는지, 다른 요소와 어떻게 구별되는지 말풍선으로 설명한다.
4. 화살표를 시작점에서 도착점으로 긋는다. 흐름의 방향, 이름, 조건 또는 전달되는 값을 설명하고 가능한 경우 중간 상태를 보여 준다.
5. 전체 흐름을 다시 연결한다. 달라지는 입력과 그대로 유지되는 항목을 구분하고, 실제 예시에서 예상한 결과가 나오는지 확인한다.

사용자가 간단히 해 달라고 했을 때만 단계 수와 설명량을 줄인다. 상세 버전은 한 요소나 관계마다 말풍선 하나를 기본으로 둔다. 문장이 길어지면 두 차례로 나눈다. 한 문장을 읽고 도형을 확인할 시간이 있도록 다음 말풍선까지 보통 3초 이상 확보한다. 빠른 자동 재생 중에만 보이는 핵심 정보를 줄이고 레이블로도 남긴다.

수식이 있는 경우 기호의 뜻, 단위, 계산 조건을 첫 등장에 설명한다. 예시와 수치 단언을 다시 계산한다. 색과 함께 이름, 형태, 방향을 쓴다. 시각화 대상이 실제 과정의 단순 모형이면 어떤 관계를 보이려는지 설명한다.
