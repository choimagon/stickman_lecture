# 스틱 설명자와 말풍선

스틱 레이어의 `bubble`에 첫 대사를 설정한다. 별도 값이 없으면 첫 설명자는 장면의 `narration`으로 시작한다. `speak`는 설명자의 대사를 지정한 시점에 바꾼다. 빈 문자열을 주면 말풍선이 닫힌다. 말풍선에 들어가는 문장은 최대 두세 줄로 나눈다.

`idle`, `point_right`, `explain`, `wave`를 쓸 수 있다. 자세가 다른 `gesture`를 설명할 도형의 등장이나 그리기 시작과 맞추면 0.32초 동안 자세가 바뀐다. 발 위치는 고정된다. 웹의 모션 감소 환경에서는 자세를 즉시 바꾼다.

말풍선을 통해 해당 요소가 하는 일과 앞뒤 관계를 설명한다. 용어와 수치 레이블은 도형 가까이에 둔다. 화면 아래에 별도 설명 문단을 넣는 대신 말풍선의 등장 시간을 늘리거나 문장을 분리한다.
