# 화면 배치

기본 `stick-studio`는 원본 Stick을 참고한 흰 바탕, 옅은 바닥 면, 가는 손그림 지면선과 검은 캐릭터를 쓴다. 밝은 노랑 말풍선으로 설명을 그림 옆에 둔다.

1280×720 기준 화면 상단 115픽셀을 제목에 남긴다. 설명자의 발은 x≈205, y≈550을 권장한다. 말풍선은 설명자 머리 위에서 가로 약 315픽셀까지 차지할 수 있다. 주요 그림은 x 405–1200, y 145–620 안에 배치한다. 화면 높이의 약 89퍼센트부터 지면을 그린다.

텍스트는 `foreground`, 흰 도형의 채움은 `surface`를 사용한다. `blue`, `amber`, `teal`, `rose`는 주요 그룹, `muted`와 `grid`는 기준과 보조선으로 쓴다. `blue-tint`, `amber-tint`, `teal-tint`는 밝은 도형 채움에 쓴다. 의미를 전달할 때 색과 함께 이름, 방향, 위치를 사용한다.

서로 다른 단계에는 다른 동작을 쓴다. 예를 들어 도형 윤곽, 연결 화살표, 이름, 결과값 순으로 보인다. 설명자가 말할 때 관련 요소의 위치와 레이블이 한눈에 들어오도록 한다. 웹에서는 좁은 화면에서 읽기 쉬운 말풍선을 그림 위에 표시한다.
