# 화면 배치

1280×720 기준으로 상단 제목 영역에 115픽셀을 남긴다. 설명자는 x 180–270에서 발을 y 490–540에 두고, 핵심 시각화는 x 405–1200과 y 165–560 안에 배치한다. MP4 하단은 자막 공간으로 남긴다. 좌표계를 바꿀 때 제목과 자막 공간도 다시 확인한다.

팔레트 키는 `blue`, `amber`, `teal`, `rose`, `white`, `muted`, `grid`, `ink`다. 파랑은 입력 및 예측, 호박색은 비교 및 관측, 청록은 결과를 기본으로 삼는다. 축 레이블, 값, 기호를 함께 넣는다.

영상은 ManimCE와 Pango, 웹은 SVG와 KaTeX를 사용한다. 글꼴이 달라질 수 있으니 긴 한국어 제목과 수식은 여유 있게 놓는다. 모바일에서 본문의 글자가 지나치게 작아지면 글을 줄이고 설명과 기호 정의를 페이지 텍스트에도 넣는다.
