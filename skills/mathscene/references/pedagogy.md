# 수학 장면 작성 지침

## 여섯 단계

1. **왜**: 학습자가 알고 싶은 질문이나 문제를 제시한다.
2. **직관**: 그림과 일상적인 표현으로 핵심 관계를 보여 준다.
3. **예시**: 작은 숫자로 계산 과정을 단계별로 드러낸다.
4. **수식**: 예시를 일반화하고 각 기호의 의미를 연결한다.
5. **통찰**: 입력이나 가정을 바꾸어 결과가 달라지는 이유를 살핀다.
6. **정리**: 질문에 답하고 핵심 관계와 적용 조건을 되짚는다.

각 장면에는 확인 가능한 학습 목표 하나를 둔다. 내레이션과 화면 문구는 짧게 쓰고, 한 번에 설명할 정보량을 제한한다. 수식과 그림은 설명 순서에 맞추어 공개한다. 교사의 몸짓은 설명 대상이나 장면 전환을 가리키는 데 사용한다.

## 수학 정확성

- 모든 기호를 정의하고 장면 간 표기와 단위를 일치시킨다.
- 예시의 산술을 독립적으로 다시 계산하고 일반식에 대입해 확인한다.
- 분모가 0이 아닌지, 제곱근의 범위가 유효한지 등 식의 조건을 명시한다.
- 벡터와 행렬은 차원을 확인하고 곱의 순서를 지킨다.
- 확률과 통계에서는 가정, 분포의 매개변수, 평균과 분산의 의미를 구분한다.
- 슬라이더의 양 끝과 기본값에서 식과 표시가 유효한지 검사한다. 가능한 경우 장면 데이터에 표본값이나 차원 검사를 기록한다.
- 그림의 방향, 크기, 축과 수치가 설명 및 수식과 일치하는지 확인한다. 직관을 위한 단순화는 실제 적용 조건과 구분한다.

## 배치와 검토

본문과 수식은 주 화면 영역에 배치하고 서로 겹치지 않게 충분한 간격을 둔다. 텍스트의 기본 정렬은 왼쪽이므로 시작점과 실제 너비를 함께 확인한다. 화면 밖으로 나가는 긴 수식이나 문구는 줄이거나 나눈다. 공개 시점과 교사의 몸짓을 재생해 확인하고, 마지막에는 장면별 목표와 내레이션, 수식, 시각 요소가 서로 맞는지 검토한다.
