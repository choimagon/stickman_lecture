# 검증

`validate`로 스키마, 프레임 정렬, 연속 구간, 중복 ID, 이벤트 타깃, 기호 선언, 슬라이더 바인딩, 수치 및 동치 주장부터 확인한다. 결과의 정확성을 뒷받침하는 표본 값을 작성한다.

렌더 후 `validation.json`과 `_work/run-*/`에서 단계별 로그와 프레임을 확인한다. 웹 검사는 데스크톱과 모바일 크기에서 장면 이동, 재생과 정지, 키보드 이동, 슬라이더 변화, 화면을 벗어나는 객체 및 겹치는 레이블을 확인한다. 영상 검사는 알파 레이어, 관절 이동, 발 고정, 실제 프레임 수와 전체 디코딩을 확인한다.

대표 프레임의 제목, 식, 눈금, 색 대응과 자막 줄바꿈을 눈으로 본다. 레이블 겹침 경고는 의도한 표기인지 판단한다. 기호 최초 등장 시 정의, 교수 순서, 접근성, 연속 입력 전체에서의 정확성까지 자동 검증했다고 보고하지 않는다.
