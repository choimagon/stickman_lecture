# 아키텍처

Codex는 스킬의 지침에 따라 스토리보드와 장면 JSON을 작성한다. 실행기는 자연어 대신 장면 데이터만 읽는다. 공통 JSON Schema와 파이썬 의미 검사기가 시간, 대상 식별자, 기호, 바인딩과 수학 단언을 검증한다.

브라우저와 Node는 같은 `core.js`에서 프레임에 따른 객체 가시성, 제스처 가중치, 슬라이더 값과 좌표를 구한다. 웹 렌더러는 수식에 로컬 KaTeX를, 도형에 SVG를, 캐릭터에 Canvas를 쓴다. 영상에서는 Node가 프레임 경계마다 수학 상태를 준비하고 수식을 MathJax SVG로 변환한다. ManimCE Cairo가 도형과 해당 SVG를 그리고, Chromium이 같은 시간 기준으로 투명 Canvas 프레임을 캡처한다. FFmpeg가 수학 배경과 캐릭터 및 자막을 합성하고 선택 오디오를 추가한다.

장면 간격은 정수 프레임 수로 검증한다. 영상의 모든 레이어를 ffprobe로 대조하고 최종 MP4는 전체 디코딩을 검사한다. 웹에서는 로컬 HTTP 서버와 오프라인 파일로 플레이어를 실행해 단계 이동과 조작을 검사한다. 출판 파일은 검증 후 배치하며 중간 상태와 실패 로그는 실행별 폴더에 남긴다.
