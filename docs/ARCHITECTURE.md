# 아키텍처

Codex는 스토리보드와 장면 JSON을 작성한다. 실행기는 장면 데이터만 읽는다. JSON Schema와 Python이 시간, 대상 식별자, 수치, 기호, 슬라이더 바인딩을 검증한다.

브라우저와 영상 준비 스크립트는 같은 `core.js`에서 시간에 따른 객체 가시성, 그리기 진행률, 말풍선 대사, 제스처, 슬라이더 값과 좌표를 구한다. 개방된 경로는 길이를 기준으로 순차적으로 드러나며 도형은 닫힌 윤곽이 완성될 때 채워진다. 웹은 SVG, KaTeX, Canvas를 사용한다. 영상은 ManimCE Cairo로 도형과 MathJax에서 변환한 수식 SVG를 그리고, 같은 시간의 캐릭터와 말풍선을 Chromium Canvas로 캡처한다. FFmpeg가 두 레이어를 합성한다.

시간 간격은 정수 프레임 수로 맞춘다. 영상은 ffprobe로 프레임 개수와 길이를 확인하고 전부 디코딩한다. 웹은 로컬 HTTP와 오프라인 파일에서 구간 이동, 재생, 말풍선 변경, 그리기와 슬라이더를 검사한다. 개별 실행의 로그, 중간 레이어와 스냅샷을 보관한다.
