# 아키텍처

Codex는 스토리보드와 장면 JSON을 작성한다. 실행기는 장면 데이터만 읽는다. JSON Schema와 Python이 시간, 대상 식별자, 수치, 기호, 슬라이더 바인딩을 검증한다.

브라우저와 영상 준비 스크립트는 `core.js`에서 객체 가시성, 그리기 진행률, 말풍선 대사와 트랙 값을 구한다. 트랙은 동일한 값으로 인물 위치, 소품 좌표, 그래프와 수치를 바꾼다. 손 목표는 현재 보이는 소품 좌표에서 계산하고 원본 Stick Scene 리그가 걷기와 손의 자세를 그린다. 웹은 SVG, KaTeX, Canvas를 사용한다. 영상은 ManimCE Cairo로 매 프레임의 도형과 수식을 그리고, 같은 시간의 캐릭터와 말풍선을 Chromium Canvas로 캡처한다. FFmpeg가 두 레이어를 합성한다.

시간 간격은 정수 프레임 수로 맞춘다. 영상은 ffprobe로 프레임 개수와 길이를 확인하고 전부 디코딩한다. 웹은 로컬 HTTP와 오프라인 파일에서 구간 이동, 재생, 말풍선 변경, 그리기와 슬라이더를 검사한다. 개별 실행의 로그, 중간 레이어와 스냅샷을 보관한다.
