# 구현 및 실행 결과

macOS arm64에서 Python 3.12, ManimCE 0.20.1, Chromium 145, FFmpeg 8.1로 검증했다. 생성 영상은 1280×720, 30fps H.264다. 캐릭터의 말풍선이 화면에 표시되며 별도 대사 SRT를 함께 생성했다.

| 데모 | 웹 | 영상 |
| --- | --- | --- |
| 물의 순환 | 데스크톱과 모바일 | 56초, 1680프레임 |
| MLP | 데스크톱과 모바일, 입력 조작 | 124초, 3720프레임 |
| 칼만 필터 | 이 데모의 기본 모드는 영상 | 90초, 2700프레임 |
| 고유벡터 | 데스크톱과 모바일, 고유값 조작 | 이 데모의 기본 모드는 웹 |
| RFS와 다중 베르누이 | 데스크톱과 모바일 | 36초, 1080프레임 |

`pytest` 20개가 통과했다. 지원하지 않는 그리기 대상, 장면이 끝날 때까지 완성되지 않는 윤곽, 말풍선 대상을 검증하고 MLP 연결 중간 프레임과 슬라이더 값을 비교했다. 웹 렌더링은 1440px와 390px 뷰포트에서 그리는 중간 상태 및 해당 시점의 말풍선을 확인했고, 레이블 겹침 경고는 없었다. 네 MP4는 전체 디코딩을 통과했다.

인코딩된 실제 영상에서 MLP 화살표와 칼만 예측 곡선의 시작 전, 그리는 도중, 완성 후 프레임을 비교했다. 물의 순환 다각형의 내부는 윤곽이 진행되는 동안 흰색이고 닫힌 윤곽이 완성된 후 채워졌다. README에 있는 GIF와 MP4는 완성 영상에서 추출했다.

현재 그리기 대상은 선, 방향 화살표, 꺾은선, 가우시안 곡선, 원, 타원, 사각형, 다각형이다. 수식은 단계별로 표시하거나 교체할 수 있다. 연속적인 수식 변형, 3D, TTS 및 립싱크는 후속 범위다. 자동 검증은 장면 안의 표본 시각과 작성자가 정의한 수치 주장을 대상으로 한다. Linux 설치법을 문서화했다. Linux와 Windows에서의 실제 렌더링은 확인하지 않았다.
