# 구현 및 실행 결과

macOS arm64에서 Python 3.12, ManimCE 0.20.1, Chromium 145, FFmpeg 8.1로 검증했다. 영상은 1280×720, 30fps의 무음 H.264이며 한국어 자막을 포함한다.

| 데모 | 웹 | 영상 | 수학 검사 |
| --- | --- | --- | --- |
| MLP | 1440px와 390px, 슬라이더 및 오프라인 실행 확인 | 36초, 1080프레임 | 순전파 표본 3개 |
| 칼만 필터 | 웹 내보내기 생략 | 90초, 2700프레임 | 칼만 이득 표본 |
| 고유벡터 | 1440px와 390px, 슬라이더 및 오프라인 실행 확인 | 영상 내보내기 생략 | 고유값 표본 및 행렬 차원 |
| RFS와 다중 베르누이 | 1440px와 390px, 제어 및 오프라인 실행 확인 | 36초, 1080프레임 | 집합 확률과 개수 확률 |

`pytest`는 14개를 통과했다. 잘못된 이벤트 구간과 대상, 미정의 기호, 위험한 TeX 명령, 잘못된 수치 및 차원, 깨진 바인딩이 거부되는지 포함한다. 생성한 세 MP4는 전체 디코딩을 통과했다. 웹 검증에서 레이블 겹침 경고는 없었다. 별도 작업 디렉터리에서 독립적으로 작성한 가중평균 강의도 렌더링하고 두 뷰포트에서 가중치 변화에 따른 값을 확인했다.

README의 GIF와 MP4는 실제 렌더 영상에서 자른 장면이다. 전체 데모, 대표 PNG 및 검증 로그를 생성하려면 프로젝트 루트에서 `./scripts/render-demos.sh`를 실행한다. 보고서는 각 출력 폴더의 `validation.json`에 저장된다.

현재 범위에는 2차원 도형, 가우시안 분포, 수식의 표시·교체, 슬라이더와 네 가지 설명자 자세가 포함된다. 수식의 연속 변형, 임의 Manim 프로젝트 가져오기, ManimGL, 3D, TTS, 립싱크는 후속 범위다. 슬라이더는 표본 지점에서 검사하고 수학 검증은 작성자가 제공한 단언을 대상으로 한다. Linux 설치법을 문서화했고 Linux와 Windows에서의 실제 렌더 검증은 남아 있다.
